개인정보처리방침

시행일: 2026년 10월 3일

1. 앱의 목적

이 앱은 개발자 본인이 자신의 Google 계정 데이터를 AI 도구와 MCP로 연결해 사용하기 위한 개인 전용 앱입니다.

2. 접근하는 정보

사용자가 Google 로그인 화면에서 직접 허용한 범위(예: Google Calendar, Drive, Sheets)의 데이터에만 접근합니다.

3. 정보의 사용

접근한 데이터는 사용자가 요청한 작업(일정 조회·생성, 문서 읽기·편집 등)을 수행하는 데에만 사용합니다.

4. 저장 및 제3자 제공

  • 인증 토큰은 사용자 본인의 컴퓨터에만 저장되며, 별도의 서버로 전송하지 않습니다.
  • Google 사용자 데이터를 판매하거나 광고 목적으로 사용하거나 제3자에게 제공하지 않습니다.
  • 이 앱의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

5. 접근 권한 철회

언제든지 Google 계정 → 타사 액세스에서 이 앱의 권한을 해제할 수 있습니다.
